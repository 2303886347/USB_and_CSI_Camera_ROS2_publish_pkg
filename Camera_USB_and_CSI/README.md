# camera_usb_and_csi

ROS 2 Humble image publishers for a Jetson CSI camera or a V4L2 USB camera.

The package name is `camera_usb_and_csi`; the source directory keeps the
requested display name `Camera_USB_and_CSI`. See `docs/摄像头功能包安装与使用教程.md`
for installation, udev binding, launch parameters, and rqt_image_view usage.
